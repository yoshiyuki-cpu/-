# スキル（Claude用の作業手順書）

Claude Code は、このフォルダのスキルを読んでから作業する。人が呼び出す必要はなく、
依頼の内容に合うスキルが自動で読まれる。

## 共通スキル（3つのアプリで同じものを置く。中身も同一に保つ）

| スキル | いつ効くか |
|---|---|
| `shikumika` | 仕組み化の相談を受けたとき。何を聞き、どこまで作るかの判断 |
| `supabase-migration` | DBのテーブル・列を変えるとき |
| `line-notify` | LINE通知・定時実行を足すとき |
| `release-check` | コミット・pushの前の自己点検と、報告の書き方 |
| `documents` | 見積書・請求書・シフト表など書類やファイルを作るとき |

## このリポジトリ専用（株式会社良心・工事台帳アプリ）

| スキル | いつ効くか |
|---|---|
| `add-feature` | 機能追加の道筋（SQL→型→画面→BottomNav） |
| `notifications` | このアプリの通知部品（lib/notify.ts）とcron |
| `ai-analysis` | 写真・音声をClaudeに読ませるAPI |
| `ui-style` | 画面の見た目と日本語の言い回し |

## 人が呼び出すスキル

上の表のスキルと違い、自動では動かない。人が名前を打って呼ぶ。

| スキル | いつ使うか |
|---|---|
| `grill-me` | 作りたいものがぼんやりしている段階で、決めるべきことを洗い出したいとき |

`/grill-me` と打つと、確定済みの前提から出せる質問だけをまとめて投げてくる。
答えるたびに次の枝が開き、聞くことが尽きたら終了。新しい会話で始めるとよい。
中身は `grilling` にあり、`grill-me` はそれを呼ぶだけなので2つセットで必要。

出典は [mattpocock/skills](https://github.com/mattpocock/skills)（MITライセンス）。
他の2つのリポジトリには揃えなくてよい。工事台帳に固有の内容を持たないので、
使いたければ各自のパソコンの `~/.claude/skills/` に置く手もある。

## PDF・Excel・Wordについて

ファイルを作る・読む部分は、Claudeに標準で入っている `pdf` / `xlsx` / `docx` スキルが受け持つ。
リポジトリに置く必要はない。「アプリの機能にするか、その場でファイルを渡すか」の判断は
共通スキル `documents` にある。

## 共通スキルの直し方

共通スキルはこのリポジトリ（`yoshiyuki-cpu/-`）を正とする。直したら、焼肉がみや（`-gamiya`）と
ラウンジケリー（`lounge-kelly`）の `.claude/skills/` にも同じ内容をコピーする。
Claudeに「共通スキルを3つのリポジトリに揃えて」と言えばよい。
