## grill-me / grilling

出典: [mattpocock/skills](https://github.com/mattpocock/skills) (MIT License, Copyright (c) 2026 Matt Pocock)

`/grill-me` と打つと、アイデアや設計を決定木として扱い、
「前提がすでに確定している質問」をまとめて1ラウンドずつ投げてくる
インタビューが始まります。フロンティア（未確定の分岐）が空になったら終了。

`grill-me` は `grilling` を呼び出すだけの薄いラッパーなので、
2つセットで置いておく必要があります。
