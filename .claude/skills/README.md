# スキル（Claude用の作業手順書）

Claude Code は、このフォルダのスキルを読んでから作業する。人が呼び出す必要はなく、
依頼の内容に合うスキルが自動で読まれる。

## 2階建て

**共通スキル**（3つのアプリで同じものを置く。中身も同じに保つ）

| スキル | いつ効くか |
|---|---|
| `shikumika` | 仕組み化の相談を受けたとき。何を聞き、どこまで作るかの判断 |
| `supabase-migration` | DBのテーブル・列を変えるとき |
| `line-notify` | LINE通知・定時実行を足すとき |
| `release-check` | コミット・pushの前の自己点検と、報告の書き方 |

**このリポジトリ専用**（株式会社良心・工事台帳アプリ）

| スキル | いつ効くか |
|---|---|
| `add-feature` | 機能追加の道筋（SQL→型→画面→BottomNav） |
| `notifications` | このアプリの通知部品（lib/notify.ts）とcron |
| `ai-analysis` | 写真・音声をClaudeに読ませるAPI |
| `ui-style` | 画面の見た目と日本語の言い回し |

## 共通スキルの直し方

共通スキルはこのリポジトリ（`yoshiyuki-cpu/-`）を正とする。直したら、
焼肉がみや（`-gamiya`）とラウンジケリー（`lounge-kelly`）の `.claude/skills/` にも
同じ内容をコピーする。Claudeに「共通スキルを3つのリポジトリに揃えて」と言えばよい。

各リポジトリ専用のスキルは、そのリポジトリだけに置く。
