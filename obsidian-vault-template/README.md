# ryoshin-notes（Obsidian Vault）

工事台帳アプリ（`yoshiyuki-cpu/-`）と対になる、現場記録・議事録・仕様メモの保管庫。

セットアップ手順は工事台帳リポジトリの [docs/obsidian-claude.md](https://github.com/yoshiyuki-cpu/-/blob/main/docs/obsidian-claude.md) を参照。

## フォルダの役割

| フォルダ | 入れるもの |
|---|---|
| `現場/` | 現場ごとに1ノート。工事台帳アプリの現場（projects）と1対1で対応させる |
| `議事録/` | 日付ごとの打ち合わせ記録。関係する現場ノートへ `[[佐藤様邸]]` でリンクする |
| `仕様/` | アプリや計算ロジックの設計メモ。現場向けの言葉で書く |
| `単価・相場/` | 単管・足場材・燃料などの相場メモ |
| `日誌/` | その日の気づき。あとから見返して問題の傾向を拾う |
| `テンプレート/` | 新規ノートのひな形。Obsidian の Templates プラグインから呼び出す |

## テンプレートの使い方

設定 → コアプラグイン → 「テンプレート」を有効化し、テンプレートフォルダに `テンプレート` を指定する。
新規ノートで コマンドパレット（Ctrl/Cmd + P）→「テンプレートを挿入」で選べるようになる。

## 書き方のルール

- ノート先頭のフロントマター（`---` で囲んだ部分）は消さない。Claude がノートを機械的に扱うときの手がかりになる
- 現場名は表記を揺らさない（「佐藤様邸」と「佐藤邸」を混ぜない）。リンクが切れる
- 決まったこと・決まらなかったことは分けて書く。後から「なぜそうしたか」を追える
